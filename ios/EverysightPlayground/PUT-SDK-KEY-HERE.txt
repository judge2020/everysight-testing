Place your real Everysight developer key here as sdk.key, then rebuild.
From the repository root: ios/EverysightPlayground/sdk.key

Set PRODUCT_BUNDLE_IDENTIFIER in ignored ios/Local.xcconfig to the namespace
covered by your developer key. See ios/App.xcconfig for generic build defaults.

The build copies a nonempty key into the application bundle. Without a key the app
still builds and initializes; connecting requires a real key. The key is ignored
by Git. See the root README.md for official key request and simulator instructions.
